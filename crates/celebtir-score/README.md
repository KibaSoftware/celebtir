# celebtir-score

Celebtir scorer: pure functions from facts to ratings and Stage.

A library crate of [Celebtir](https://github.com/celebtir/celebtir), an open, evidence-linked scorecard of who controls each Solana DeFi protocol. Most people want the command-line tool instead:

```bash
cargo install celebtir
```

The API follows the CLI and may change between minor versions until 1.0.
