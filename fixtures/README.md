# Fixtures

Recorded data for offline tests (QA-1, QA-3, ADR 009). Tests never touch the network.

- `accounts/<name>.json`: one mainnet account captured with
  `cargo run -p celebtir-collect-solana --example capture -- <name> <address> [--slice OFFSET:LEN] [--note "why"]`.
  Each file holds the bytes (base64), the slot read at, the owner, the RPC host (never the URL) and a note. Re-capturing changes the slot and maybe the bytes, so commit re-captures deliberately and re-run the tests.
- `facts/sample-facts.json`: hand-built facts for scorer and CLI tests (generated by `crates/celebtir-cli/tests/common/mod.rs`; regenerate with `CELEBTIR_UPDATE_FIXTURES=1 cargo test -p celebtir`).

Synthetic cases that mainnet doesn't offer (loader v4, malformed bytes) are built inside the tests that need them and named as synthetic there.
- `hyperliquid/info/<name>.json` and `hyperliquid/evm/<name>.json`: Hyperliquid info API responses (anchored to a HyperEVM block) and HyperEVM JSON-RPC calls at one pinned block, recorded by `bash scripts/capture-hyperliquid.sh` (HOPS-2, ADR 024). Tests replay them with `EvmFixture::replay()`; an unrecorded call fails.
