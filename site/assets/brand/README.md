# Brand source

`celebtir-logo.png` is the original supplied artwork. Keep editable/source
assets here, outside the publicly served directory.

From the repository root, run `pnpm.cmd -C site brand:assets` to regenerate
`site/public/brand/` and the Next metadata icons in `site/src/app/`.
The generator also works from any directory using its absolute script path.
Generated files retain their existing public URLs.
