# Changelog

This file tracks application releases. Published methodology versions are documented separately in [methodology/CHANGELOG.md](methodology/CHANGELOG.md); schema and snapshot versions retain their own compatibility contracts.

## 0.1.1 — 2026-11-02

Initial source baseline prepared for an owner-managed release.

- Rust workspace for evidence-linked collection, registry validation, deterministic scoring, change detection and static data/API generation.
- Solana protocol and token assessments, native HyperEVM contract-authority facts, and unrated HyperCore HIP-3 coverage.
- Static Next.js research interface with protocol/token profiles, risk, value and activity views, comparison, control graphs, history and methodology references.
- Assessment-first presentation, concise findings, expandable technical evidence, accessible deep links and responsive layouts.
- Versioned methodology through v0.3, preserved historical inputs, offline replay fixtures and automated validation.
- Host deployment helpers with publication verification/recovery; GitHub daily collection and Pages publication require explicit opt-in.
- Initial repository documentation and ignore rules separating source inputs from local secrets, agent worktrees, candidates and build output. The owner's root deployment entry point remains local and ignored.

The Rust packages and site package use application version 0.1.1. This preparation changes no published scores, methodology rules, API/schema versions or historical snapshot tool versions. Existing owner visual-review and hosted-release checks remain separate from this version assignment.
